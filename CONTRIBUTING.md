# Contributing

Thanks for your interest in GhostDLL.

At this early stage, technical discussion, bug reports, testing observations and documentation suggestions are welcome.

## Please do not upload

Do not submit or attach:

- original Vampire: The Masquerade – Bloodlines game files
- original executables or DLLs
- VPKs, maps, textures, models, audio or other copyrighted game assets
- files from unofficial patches or translations unless their redistribution is expressly permitted
- decompiled or reconstructed source code from the original game
- material copied from third-party projects without permission

## Code contributions

The project is not currently operating as an open-source collaborative codebase. Please do not submit substantial code contributions unless they have been discussed and explicitly requested first.

This policy may change later if a contributor agreement and a formal licensing model are introduced.
